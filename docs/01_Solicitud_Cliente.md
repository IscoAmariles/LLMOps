# Solicitud del Cliente

## Proyecto
Green Data RAG sobre Plataforma LLMOps

## Contexto
La organización requiere reemplazar el corpus de ejemplo TecnoFábrica por un conjunto de datos ambientales provenientes del proyecto Green Data ETL, con el fin de construir un asistente conversacional en español basado en arquitectura RAG.

## Necesidad de Negocio
Se requiere una solución capaz de:

- Responder preguntas sobre 20 países del dataset.
- Consultar indicadores de consumo energético y energía renovable.
- Explicar estados ambientales.
- Permitir trazabilidad de las respuestas.
- Registrar métricas, experimentos y evidencias.
- Abstenerse cuando no exista información suficiente.

## Historia de Usuario Principal

### HU-001

**Como** Analista Ambiental

**Quiero** consultar información ambiental consolidada mediante lenguaje natural

**Para** obtener respuestas confiables y sustentadas en los datos disponibles.

## Resultado Esperado

Un asistente RAG capaz de responder preguntas en español utilizando exclusivamente el corpus Green Data y mostrando evidencia verificable de sus respuestas.
